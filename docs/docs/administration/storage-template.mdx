# Storage Template

<StorageTemplate />

:::info S3 storage
The storage template also applies to files stored in [S3-compatible storage](/features/s3-storage). New uploads move to their template path inside the bucket, and the `Storage Template Migration` job moves existing objects. See [Storage Template on S3](/features/s3-storage#storage-template-on-s3) for how a move works there and what it costs.
:::
