# Slice 3 — `/search/suggestions` accepts `city` and `mediaType` (#858)

- **Spec:** `docs/superpowers/specs/2026-07-26-second-level-filter-narrowing-858-design.md` § "Slice 3"
- **Branch:** `fix/858-second-level-filter-narrowing`
- **Depends on:** Slice 1 (`b24866b7c66`) and Slice 2 (`02b91205611`) — the repository already applies both
  fields; this slice only lets clients send them.
- **Scope:** one DTO schema + three unit test files + regenerated API clients.

## Outcome

`SearchSuggestionRequestDto` stops silently dropping `city` and `mediaType`. Today it accepts `country`,
`make`, `model` but not `city` or `mediaType`, while its sibling `FilterSuggestionsRequestDto` accepts all
five — the two request schemas have drifted. Slice 4 needs both fields to send the panel's full filter
context.

No repository or service change is needed: `buildFilteredAssetIds` already reads `options.city` and
`options.mediaType`, and `SearchService.getSuggestions` already forwards the whole DTO.

## Out of scope

- `web/`, `mobile/lib/` → Slice 4 / non-goal. (`mobile/openapi/**` IS regenerated here — it is generated
  client code, not hand-written mobile code.)
- `open-api/typescript-sdk/**` — a stale pre-move leftover (the SDK now lives in `packages/sdk`). It is not
  regenerated by `mise open-api` and nothing imports it. **Do not touch it**, and do not "helpfully" delete
  it either.
- Any repository or service logic.

## Step 1 (RED) — DTO schema tests

**File:** `server/src/dtos/search.dto.spec.ts`

Read the file first — it already tests `FilterSuggestionsRequestDto.schema.safeParse(...)`. Match its style.
`SearchSuggestionRequestDto` may need adding to the import list on line 1-6.

Note `SearchSuggestionRequestSchema` is `SearchSuggestionRequestBaseSchema.pipe(IsNotSiblingOf(...))`, so
`safeParse` returns the piped result; `type` is REQUIRED, so every fixture must include it.

```ts
describe('SearchSuggestionRequestDto (#858)', () => {
  it('accepts a city filter', () => {
    const result = SearchSuggestionRequestDto.schema.safeParse({ type: 'camera-model', city: 'Berlin' });
    expect(result.success).toBe(true);
    expect(result.data?.city).toBe('Berlin');
  });

  it('accepts a mediaType filter', () => {
    const result = SearchSuggestionRequestDto.schema.safeParse({ type: 'camera-model', mediaType: 'IMAGE' });
    expect(result.success).toBe(true);
    expect(result.data?.mediaType).toBe(AssetType.Image);
  });

  it('rejects an unknown mediaType', () => {
    const result = SearchSuggestionRequestDto.schema.safeParse({ type: 'camera-model', mediaType: 'NOT_A_TYPE' });
    expect(result.success).toBe(false);
  });
});
```

`AssetType` comes from `src/enum`. If the existing file already imports it, reuse; otherwise add the import.
